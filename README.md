# djohn.github.io

Personal website for Alex Johnson — PM job search.

## Edit content
Open `config.js` and update the `profile` object. That's the only file you need to touch for copy and link changes.

## Preview locally
Open `index.html` in any browser. No build step or local server needed.

## Deploy
Push to `main` → GitHub Pages auto-deploys at `djohn.github.io`.
